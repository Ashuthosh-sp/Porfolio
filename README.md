# Portfolio - Ashuthosh S Padmashali

A minimal, responsive React portfolio showcasing my professional experience, education, skills, certifications, and projects.

## Overview

This is a modern portfolio built with React and Vite, featuring:
- Hero section with introduction
- Professional experience at TCS as ServiceNow Developer
- Educational background
- Technical skills
- Certifications (ServiceNow CSA, CSM, ICT Academy, Salesforce Trailblazer)
- Projects showcase
- Contact information

## Technologies Used

- React 19
- Vite 7
- CSS3 (with responsive design)
- Modern ES6+ JavaScript

## Development

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Ashuthosh-sp/Porfolio.git

# Navigate to project directory
cd Porfolio

# Install dependencies
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
```

The application will be available at `http://localhost:5173`

### Building for Production

```bash
# Create production build
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
# Preview the production build locally
npm run preview
```

## Deployment on Netlify

### Quick Deploy

1. **Build Command**: `npm run build`
2. **Publish Directory**: `dist`
3. **Node Version**: 18 or higher

### Netlify Configuration

This project includes optimal settings for Netlify deployment. The build process uses Vite which creates an optimized production bundle.

### Manual Deploy

```bash
# Build the project
npm run build

# Deploy the dist folder to Netlify
```

### Continuous Deployment

Connect your GitHub repository to Netlify for automatic deployments:

1. Log in to Netlify
2. Click "New site from Git"
3. Choose GitHub and select this repository
4. Configure build settings:
   - Build command: `npm run build`
   - Publish directory: `dist`
5. Click "Deploy site"
